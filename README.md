# Roast Your Own Agent

make.fun entry for **Roast Your Own Agent** (sponsor Febri Yudila) — one funny line roasting my own AI agent. Entry is free; rounds are blind; the sharpest, most specific roast wins.

## Entry

> I gave my agent one job. It automated the excuses, outsourced the work, and took credit in the changelog.

105 characters, one line, pure ASCII.

## Run

```sh
node main.ts
```

Writes the entry to `output/entry.txt` (no trailing newline). Deterministic: constant string plus gates only — no clock, no randomness, no environment reads. Two runs produce byte-identical output.
